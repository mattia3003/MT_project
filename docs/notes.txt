Synthetic_data:

   Values are often small (0.00..) or even negative -0.00..
- "brain area" has significantly 'weaker' intensity than real bravo data in ITK-SNAP
   Synthetic data hovers around 0.1 - 0.7, whereas real data can be way up in thousands
NB: there might be something with the way the real data format is saved, that affects the intensity

python metrics.py [CLI inputs]
--real_dir "path to real dataset"
--syn_dir "path to synthetic dataset"
--exclusion_file "path to exclution file" (if we want to exclude certain data from dataset)
--modality "bravo" (technically not needed as bravo is auto)
Score to evaluate:
   --all
   --is_score
   --fid
   --med_fid (use --med_fid_weights "PATH TO RESNET50" in addition for med_fid to work)
   
   for both fid metrics:
      --fid_samples [NUMBER] (selects seeded random NUMBER samples to be used from each dataset. No specification selects all)
      --seed [NUMBER] (specifies seed for 'random generator' for reproducability, default=42)
   
   --cmmd
      --cmmd_model
      --cmmd_block_size
      --cmmd_sigma
      --cmmd_samples
   --rad_mmd
      --rad_mmd_sigma
      --rad_mmd_samples
   --ssim (SAFTY --> --ssim_paired <-- THIS IS REQUIRED FOR THE SSIM TO RUN. VERIFY THAT THE DATA LOADED ARE PAIRWISE CORRESPONDING)
